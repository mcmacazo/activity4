# Hypotenuse Calculator

## Description

This program finds the hypotenuse of a right triangle. The user types in the two shorter sides and the program uses the Pythagorean theorem (c = square root of a² + b²) with the math library to get the answer.

## How to Run

1. Open the project folder in any Python editor.
2. Open `hypotenuse.py`.
3. Run the file.
4. Type the side lengths when the program asks.

## Input Needed

- Side a (length of the first shorter side)
- Side b (length of the second shorter side)

## Sample Output


=== Right Triangle Hypotenuse Calculator ===
Enter the length of side a: 3
Enter the length of side b: 4

The hypotenuse is 5.00
